Sprite

Draws frames from a spritesheet image onto the canvas. Works with Animator to drive frame selection. Coordinates are pixel-snapped to prevent sub-pixel blurring.

SpriteFrame (interface)

An explicit source rectangle within the spritesheet image, used by drawRect().

sx: number Source X in the spritesheet image (pixels from left).
sy: number Source Y in the spritesheet image (pixels from top).
sw: number Source width in pixels.
sh: number Source height in pixels.

Sprite

new Sprite(img: HTMLImageElement, frameWidth?: number, frameHeight?: number) Creates a sprite from a loaded image. frameWidth and frameHeight define the size of a single cell in the spritesheet grid. If omitted, the full image size is used (single-frame sprite).
frameWidth: number Width of a single frame cell in pixels.
frameHeight: number Height of a single frame cell in pixels.
draw(ctx: CanvasRenderingContext2D, x: number, y: number, col?: number, row?: number, destW?: number, destH?: number): void Draws the frame at grid column col, row row (both default 0) to screen position (x, y). destW / destH override the drawn size; default to frameWidth / frameHeight.
drawRect(ctx: CanvasRenderingContext2D, frame: SpriteFrame, x: number, y: number, destW?: number, destH?: number): void Draws using an explicit SpriteFrame source rectangle instead of a grid position. Use when your spritesheet frames are not uniform in size. 
import { Sprite }   from "./engine/Sprite";
import { Animator } from "./engine/Animator";

// create sprite from a 4-column × 2-row spritesheet (48×48 cells)
const sprite = new Sprite(engine.assets.get("hero"), 48, 48);
const anim = new Animator()
  .add("idle", { frames: [{ col:0,row:0 }], fps: 1 })
  .add("run",  { frames: [{ col:0,row:1 },{ col:1,row:1 },{ col:2,row:1 },{ col:3,row:1 }], fps: 10 });

// in render():
anim.update(dt);
const { col, row } = anim.frame;
sprite.draw(ctx, this.x, this.y, col, row);

// draw scaled up 2×
sprite.draw(ctx, this.x, this.y, col, row, 96, 96);

// draw with explicit source rect
sprite.drawRect(ctx, { sx: 0, sy: 0, sw: 48, sh: 48 }, this.x, this.y);
