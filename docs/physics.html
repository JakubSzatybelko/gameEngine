Physics

Simple rigid-body physics. Register PhysicsBody instances with engine.physics (a PhysicsWorld) and they are automatically stepped each frame.

Vec2 (interface)

x: number Horizontal component.
y: number Vertical component.

PhysicsBody

A simulated body with position, velocity, and configurable physical properties. Create one and register it with the world via engine.physics.add().

x: number World-space horizontal position. Set directly to place the body.
y: number World-space vertical position.
vx: number Horizontal velocity in px/s.
vy: number Vertical velocity in px/s.
mass: number Mass in game units. Affects how forces are converted to acceleration. Default 1.
gravityScale: number 1 = full world gravity, 0 = weightless, -1 = floats upward. Default 1.
drag: number Velocity damping per second. 0 = no drag, 0.5 = 50% velocity loss per second. Default 0.
restitution: number Bounciness coefficient. 0 = no bounce, 1 = perfect elastic. Default 0.
applyForce(fx: number, fy: number): void Accumulates a continuous force (Newtons). Converted to acceleration via a = F / mass. Cleared at the end of each frame. Call every frame to sustain — good for thrust, wind, springs.
applyImpulse(ix: number, iy: number): void Applies an instantaneous change in velocity (impulse / mass). Call once — good for jumps, explosions, or collisions.
applyAcceleration(ax: number, ay: number): void Directly adds to velocity with no mass division. Good for steering behaviours or raw velocity nudges.

PhysicsWorld

Accessed via engine.physics. Manages all registered bodies and steps them each frame.

gravity: Vec2 Global gravity applied to all bodies. Default { x: 0, y: 980 } (Earth-like downward, in px/s²). Set to { x: 0, y: 0 } for space / top-down.
add(body: PhysicsBody): PhysicsBody Registers a body with the world. Returns the body for chaining.
remove(body: PhysicsBody): void Unregisters a body; it will no longer be stepped.
step(dt: number): void Advances all registered bodies by dt seconds. Called automatically by the engine each frame. 
import { PhysicsBody } from "./engine/Physics";

class Ball implements GameObject {
  body = engine.physics.add(new PhysicsBody());

  constructor() {
    this.body.x = 400;
    this.body.y = 100;
    this.body.restitution = 0.7;
  }

  update(dt: number) {
    // read position from body each frame
    const { x, y } = this.body;
    // floor bounce
    if (y > 550) { this.body.y = 550; this.body.vy = -Math.abs(this.body.vy) * this.body.restitution; }
  }

  render(ctx: CanvasRenderingContext2D) {
    ctx.beginPath();
    ctx.arc(this.body.x, this.body.y, 20, 0, Math.PI * 2);
    ctx.fill();
  }
}
