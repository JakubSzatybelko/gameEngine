Camera

2D world camera accessed via engine.camera. Translates and scales the canvas so game objects are drawn relative to a world position. Supports smooth following with configurable lerp and zoom.

x: number Current horizontal offset of the camera in world space. Updated automatically when following a target.
y: number Current vertical offset of the camera in world space.
zoom: number Scale multiplier. 1 = no zoom, 2 = 2× magnification. Default 1.
lerp: number Follow smoothness. 1 = instant snap, 0.1 = very smooth lag. Default 1. Uses frame-rate-independent exponential decay.
follow(fn: () => { x: number; y: number }): void Sets a target for the camera to follow. Pass a function that returns the current world position to track. The camera centres the returned position on screen each frame.
unfollow(): void Stops following the current target. Camera position remains where it was.
update(dt: number, width: number, height: number): void Advances the lerp toward the follow target. Called automatically by the engine each frame.
apply(ctx: CanvasRenderingContext2D, width: number, height: number): void Applies the camera transform (translate + scale) to the canvas context. Called automatically by the engine inside ctx.save/restore. 
// follow the player with smooth lag
engine.camera.lerp = 0.08;
engine.camera.follow(() => ({ x: player.x, y: player.y }));

// zoom in
engine.camera.zoom = 1.5;

// stop following (e.g. during a cutscene)
engine.camera.unfollow();
