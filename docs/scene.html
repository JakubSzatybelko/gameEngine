Scene

Organise your game into discrete states — main menu, gameplay, game over — each as a Scene subclass. Use engine.scenes.load() to switch between them.

Scene (abstract class)

Extend this class to define a scene. When loaded, the engine clears all current game objects before calling onEnter.

onEnter(engine: Engine): void Called once when the scene becomes active. Add your game objects and initialise state here.
onExit(engine: Engine): void Called once just before the scene is replaced by another. Use for any cleanup needed before clearObjects() runs. 
import { Scene } from "./engine/Scene";
import { Engine } from "./engine/Engine";

class GameplayScene extends Scene {
  onEnter(engine: Engine) {
    engine.assets.image("player", "/sprites/player.png");
    engine.assets.loadAll().then(() => {
      engine.add(new Player(engine));
    });
  }
  onExit(engine: Engine) {
    engine.audio.stopMusic();
  }
}

SceneManager

Accessed via engine.scenes. Handles loading and switching scenes.

active: Scene | null The currently loaded scene, or null if no scene has been loaded yet.
load(scene: Scene): void Transitions to a new scene. Calls onExit on the current scene, calls engine.clearObjects(), then calls onEnter on the incoming scene. 
// switch to a different scene at any time
engine.scenes.load(new GameOverScene(score));

// check the active scene
console.log(engine.scenes.active);
