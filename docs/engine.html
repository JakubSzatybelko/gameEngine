Engine

The central class. Owns the canvas, drives the game loop, and exposes every built-in system. Instantiate once and call start() to begin rendering.

new Engine(canvas: HTMLCanvasElement, width: number, height: number) Sets the canvas dimensions to width × height and obtains the 2D rendering context. Throws if a 2D context is unavailable.
canvas: HTMLCanvasElement The canvas element the engine renders into.
ctx: CanvasRenderingContext2D The 2D context. Available for direct drawing when needed.
width: number Canvas width in pixels.
height: number Canvas height in pixels.
input: Input Keyboard input system. See Input.
scenes: SceneManager Scene transition manager. See Scene.
camera: Camera World camera. See Camera.
assets: AssetLoader Image asset registry. See AssetLoader.
audio: AudioManager Sound and music system. See AudioManager.
physics: PhysicsWorld Physics simulation world. See Physics.
start(): void Begins the requestAnimationFrame game loop. Call once after scene setup.
add(obj: GameObject): void Registers a game object. It will receive update(dt) and render(ctx) each frame.
remove(obj: GameObject): void Unregisters a game object, stopping its update and render calls.
removeAll(objs: GameObject[]): void Removes every object in the provided array in a single pass. More efficient than calling remove() in a loop — uses a Set internally and only rebuilds the render order once.
addUI(el: UIElement): void Adds a HUD/UI overlay. UI renders above game objects and is not affected by the camera transform. See UIElement.
removeUI(el: UIElement): void Removes a previously added UI element.
