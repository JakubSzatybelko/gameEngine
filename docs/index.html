GameEngine

A TypeScript 2D game engine built on the HTML5 Canvas API. Provides a game loop, scene management, keyboard input, camera, physics, animation, asset loading, audio, and sprite rendering — with zero external dependencies.

Modules

Engine
Core game loop, object management, and access to all systems.
Interfaces
GameObject, UIElement, and Bounds — the contracts objects must satisfy.
Scene
Scene lifecycle with onEnter / onExit and scene switching.
Input
Keyboard state per frame: held, just-pressed, just-released.
Camera
2D world camera with follow target, smooth lerp, and zoom.
Physics
Rigid body simulation — gravity, forces, impulses, drag, bounce.
Animator
Spritesheet animation with named clips, fps control, and looping.
AssetLoader
Preload and retrieve image assets by key.
AudioManager
Sound effects, looping music, and procedural tones via Web Audio.
Sprite
Draw individual spritesheet frames to the canvas.

Quick Start

import { Engine } from "./engine/Engine";
import { Scene }  from "./engine/Scene";

const canvas = document.getElementById("gameCanvas") as HTMLCanvasElement;
const engine = new Engine(canvas, 800, 600);

class GameScene extends Scene {
  onEnter(engine: Engine) {
    // add game objects, load assets, start music ...
  }
  onExit(engine: Engine) {
    // cleanup
  }
}

engine.scenes.load(new GameScene());
engine.start();

Frame Order

Each frame produced by engine.start() executes in this order:

  1. Physics world stepped
  2. Camera updated (lerp toward follow target)
  3. GameObject.update(dt) called for every object
  4. Collision detection — onCollide callbacks fired
  5. Canvas cleared
  6. GameObject.render(ctx) called, sorted by zIndex, inside camera transform
  7. UIElement.render(ctx) called — no camera transform applied
  8. Input state flushed (clears pressed / released sets)
