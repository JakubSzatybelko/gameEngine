Input

Keyboard state tracker. Accessed via engine.input. Tracks three distinct states per key each frame: held, just-pressed, and just-released. Uses standard KeyboardEvent.code values.

Key codes — use KeyboardEvent.code strings such as "ArrowLeft", "KeyW", "Space", "Digit1". These are layout-independent and not affected by Shift or locale.
isDown(code: string): boolean Returns true every frame the key is held down. Use for continuous actions like movement.
isPressed(code: string): boolean Returns true only on the first frame the key is pressed. Use for one-shot actions like jumping or firing.
isReleased(code: string): boolean Returns true only on the frame the key is released.
flush(): void Clears the pressed and released sets. Called automatically by the engine at the end of each frame — you do not need to call this yourself. 
update(dt: number) {
  // held — smooth movement
  if (engine.input.isDown("ArrowRight")) this.x += 200 * dt;
  if (engine.input.isDown("ArrowLeft"))  this.x -= 200 * dt;

  // just-pressed — single jump
  if (engine.input.isPressed("Space")) this.jump();

  // just-released — charge release
  if (engine.input.isReleased("KeyZ")) this.fireCharged();
}
