AssetLoader

Image asset registry accessed via engine.assets. Queue images with image(), wait for them all with loadAll(), then retrieve them by key with get().

image(key: string, url: string): this Queues an image to be loaded. Returns this for chaining. Loading begins immediately in the background.
loadAll(): Promise<void> Resolves when all queued images have finished loading. Rejects with an error if any image fails to load.
get(key: string): HTMLImageElement Returns the loaded image by key. Throws if the key is not registered. 
// in Scene.onEnter:
engine.assets
  .image("player",    "/sprites/player.png")
  .image("tileset",   "/sprites/tileset.png")
  .image("explosion", "/sprites/explosion.png");

await engine.assets.loadAll();

// now safe to use:
const playerSprite = new Sprite(engine.assets.get("player"), 48, 48);
