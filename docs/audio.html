AudioManager

Web Audio API wrapper accessed via engine.audio. Supports one-shot sound effects, looping background music, a master volume control, and procedural tone generation — no audio files required for the latter.

Browser policy — browsers block audio until a user gesture. The engine automatically calls resume() on the first keypress. If you trigger audio before any input, call engine.audio.resume() manually inside a click or keydown handler.
masterVolume: number Get or set the master volume for all audio. Clamped to 0 – 1.
musicVolume (set): number Set the volume of the currently playing music track. Has no effect if no music is playing.
async load(key: string, url: string): Promise<void> Fetches and decodes a single audio file, stored under key. Throws on network errors or unsupported formats.
async loadAll(entries: Record<string, string>): Promise<void> Loads multiple audio files in parallel. Pass an object of { key: url } pairs. Resolves when all files are decoded.
play(key: string, volume?: number): void Plays a one-shot sound effect. Multiple calls overlap. volume defaults to 1.
playMusic(key: string, volume?: number): void Starts a looping music track. Stops any currently playing track first. volume defaults to 0.5.
stopMusic(): void Stops the currently playing music track.
tone(freq: number, duration: number, volume?: number, type?: OscillatorType): void Generates and plays a procedural tone — no audio file needed. freq in Hz, duration in seconds. volume defaults to 0.3, type defaults to "square". OscillatorType values: "sine", "square", "sawtooth", "triangle".
resume(): Promise<void> Resumes the AudioContext after a browser autoplay block. Called automatically by the engine on first keypress. 
// load audio files
await engine.audio.loadAll({
  jump:  "/audio/jump.wav",
  coin:  "/audio/coin.wav",
  theme: "/audio/theme.ogg",
});

// play effects
engine.audio.play("jump");
engine.audio.play("coin", 0.6);  // quieter

// background music
engine.audio.playMusic("theme", 0.4);
engine.audio.musicVolume = 0.2;  // fade down
engine.audio.stopMusic();

// procedural beeps (retro style — no file needed)
engine.audio.tone(440, 0.1);             // A4, square wave
engine.audio.tone(880, 0.05, 0.5, "sine");  // A5, sine
