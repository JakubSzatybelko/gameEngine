Animator

Spritesheet animation controller. Register named clips, call play() to switch between them, and call update(dt) each frame. Read frame to get the current column/row to pass to Sprite.draw().

AnimationFrame (interface)

col: number Zero-based column index in the spritesheet.
row: number Zero-based row index in the spritesheet.

AnimationConfig (interface)

frames: AnimationFrame[] Ordered list of spritesheet frames that make up the clip.
fps: number Frames per second for this clip.
loop?: boolean Whether the clip loops. Default true. Set to false for one-shot animations like attacks or deaths.

Animator

done: boolean Becomes true when a non-looping animation finishes its last frame. Reset to false when play() is called again.
frame: AnimationFrame The current frame's column and row. Pass these to Sprite.draw().
name: string The name of the currently playing animation clip.
add(name: string, config: AnimationConfig): this Registers a named animation clip. Returns this for chaining.
play(name: string): void Switches to the named clip from the beginning. No-op if the clip is already playing. Throws if the clip name is not registered.
update(dt: number): void Advances the animation timer. Call once per frame inside your GameObject.update(). 
import { Animator } from "./engine/Animator";
import { Sprite }   from "./engine/Sprite";

const sprite = new Sprite(engine.assets.get("player"), 48, 48);
const anim = new Animator()
  .add("idle", { frames: [{ col:0,row:0 },{ col:1,row:0 }], fps: 4 })
  .add("run",  { frames: [{ col:0,row:1 },{ col:1,row:1 },{ col:2,row:1 },{ col:3,row:1 }], fps: 12 })
  .add("jump", { frames: [{ col:0,row:2 }], fps: 1, loop: false });

// in update:
anim.update(dt);
if (isMoving) anim.play("run");
else          anim.play("idle");

// in render:
const { col, row } = anim.frame;
sprite.draw(ctx, this.x, this.y, col, row);
