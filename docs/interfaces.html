Interfaces

Core contracts that objects in the engine must satisfy. Implement these interfaces on your own classes to participate in the game loop, collision system, and UI layer.

GameObject

Implement this interface on any object you want to add to the world via engine.add().

zIndex?: number Render order. Lower values draw first (behind). Defaults to 0.
collidable?: boolean Set to true to include this object in collision checks. Requires bounds to be set.
bounds?: Bounds Axis-aligned bounding rectangle used for collision detection and click hit-testing. See Bounds below.
update(dt: number): void Called every frame. dt is the elapsed time in seconds since the last frame.
render(ctx: CanvasRenderingContext2D): void Called every frame after update. Draw your object here. The canvas transform already has the camera applied.
onClick?(): void Optional. Fired when the user clicks inside bounds. The topmost object (highest zIndex) receives the event first; propagation stops at the first hit.
onCollide?(other: GameObject): void Optional. Fired when this object's bounds overlaps another collidable object's bounds. 
class Player implements GameObject {
  x = 0; y = 0; size = 48;
  collidable = true;

  get bounds() {
    return { x: this.x, y: this.y, width: this.size, height: this.size };
  }

  update(dt: number) { /* move ... */ }
  render(ctx: CanvasRenderingContext2D) { ctx.fillRect(this.x, this.y, this.size, this.size); }
  onCollide(other: GameObject) { console.log("hit", other); }
}

UIElement

Implement this interface for HUD overlays, menus, or any canvas drawing that should remain fixed to the screen (not affected by the camera).

update?(dt: number): void Optional. Called every frame before render. Use for animating UI state.
render(ctx: CanvasRenderingContext2D): void Called every frame. Draw HUD elements here. Coordinates are always in screen space.

Bounds

An axis-aligned rectangle used by collision detection and click hit-testing.

x: number Left edge of the rectangle in world space.
y: number Top edge of the rectangle in world space.
width: number Width in pixels.
height: number Height in pixels.
